                           SORUN GİDERME
================================================================================

- HATA: "No supported browser found"
  -> Chrome, Edge veya Brave'nin varsayılan yollarda kurulu olduğundan emin olun.

- HATA: "NtCreateDebugObject (Syscall) failed"
  -> Programı Yönetici (Administrator) olarak çalıştırın.
  -> Antivirüs / EDR'yi geçici olarak devre dışı bırakın (CrowdStrike, Defender bazen engeller).

- HATA: "Timeout waiting for breakpoint"
  -> Tarayıcı sürümü güncel olmayabilir veya güncellenmiş olabilir.
  -> "OSCrypt.AppBoundProvider.Decrypt.ResultCode" kalıbı değişmiş olabilir.
  -> FindLEAInstructionInRemoteProcess içindeki kalıbı güncellemeyi deneyin.

- Veri çıkarılmadı (0 parola/çerez)
  -> Tarayıcı kapalı olabilir veya master anahtarı çözülemedi.
  -> Çalıştırmadan önce tarayıcının arka planda ÇALIŞMADIĞINDAN emin olun
    (program, browser_terminator aracılığıyla mevcut süreçleri sonlandırır).

- Telegram gönderme başarısız
  -> İnternet bağlantınızı kontrol edin.
  -> Bot token ve chat ID'nin doğru olduğunu doğrulayın.

PROGRAM EXECUTION FLOW:
1. The program detects installed browsers (Chrome, Edge, Brave).
2. It starts the target browser in a suspended state (CREATE_SUSPENDED).
3. Attaches a debugger to the process using indirect syscalls (NullGate).
4. Locates the OSCrypt.AppBoundProvider.Decrypt function in the browser DLL.
5. Sets a Hardware Breakpoint (DR0) on the LEA instruction that loads the master key.
6. Resumes the browser.
7. When the breakpoint hits, it reads the master key from the R14/R15 register.
8. Terminates debugger attachment and clears breakpoints from all threads.
9. Extracts and decrypts browser data:
   - Passwords (logins)
   - Cookies
   - Tokens (Web Data)
   - Credit Cards
10. Collects system information (OS, IP, Hostname).
11. Takes a screenshot of the desktop.
12. Compresses all collected data into a ZIP file.
13. Sends the ZIP file to the specified Telegram chat.

ARGUMENTS:
The program currently does NOT require command-line arguments.
It runs in full-auto mode.

OUTPUT (on success):
The ZIP file is sent to Telegram. No local files are kept (self-cleaning).

================================================================================
                               TROUBLESHOOTING
================================================================================

- ERROR: "No supported browser found"
  -> Ensure Chrome, Edge, or Brave is installed in the default paths.

- ERROR: "NtCreateDebugObject (Syscall) failed"
  -> Run the program as Administrator.
  -> Disable Antivirus / EDR temporarily (CrowdStrike, Defender sometimes block).

- ERROR: "Timeout waiting for breakpoint"
  -> The browser version might be outdated or updated.
  -> The pattern "OSCrypt.AppBoundProvider.Decrypt.ResultCode" may have changed.
  -> Try updating the pattern in FindLEAInstructionInRemoteProcess.

- No data extracted (0 passwords/cookies)
  -> Browser may be closed or the master key failed to decrypt.
  -> Ensure the browser is NOT already running in the background before execution
    (the program terminates existing processes via browser_terminator).

- Telegram send failure
  -> Check your internet connection.
  -> Verify the bot token and chat ID are correct.
